# Twitter_Sentiment_Analysis.ipynb📊  

This project performs sentiment analysis on Twitter data using machine learning techniques. The dataset used is **"Twitter Entity Sentiment Analysis"** from Kaggle.  

## 📂 Dataset  
The dataset is sourced from [Kaggle: Twitter Entity Sentiment Analysis]([https://www.kaggle.com/](https://www.kaggle.com/datasets/jp797498e/twitter-entity-sentiment-analysis))
